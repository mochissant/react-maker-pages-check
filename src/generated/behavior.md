# 振る舞いの表

名称未設定のプロジェクト（保存版 5）

GUIの「操作」「状態と表示」と、画面の遷移などの操作を整理した表です。動作は上から順に実行し、失敗したら後続を止めます。
取り込み部品や手書きコードの内部、データAPI・標準フォームの内部処理は、この表だけでは分かりません。担当者がソースと引き継ぎ資料を確認してください。
